# Fireworks

### 1. Prerequisites
- Install .NET 8.0 SDK
- MonoGame templates are installed

### 2. Clone the Repository
Open a terminal and run:
```bash
git clone <repository-url>
cd fireworks
```

### 3. Build the Project
Still in the terminal:
```bash
dotnet build
```
### 4. Run the Project
1. Open Visual Studio from the terminal with the sln file:
    ```bash
    devenv FireworksSimulator.sln
    ```
2. Click the green "Start" button or press F5 to run the code.

### 5. Simulate Fireworks
1. Press the space bar to spawn fireworks.
