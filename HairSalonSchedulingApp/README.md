# Hair Salon Scheduling System 💇‍♂️✨

A modern web application for managing hair salon appointments, built with React and Flask. Whether you need a fresh haircut for a job interview or want to get your hair dyed in exciting colors, our platform connects you with skilled professionals for all your hair care needs.

## 🌟 Key Features

### 💅 Professional Hair Services

- Wide range of services from simple trims to complete makeovers
- Expert stylists and colorists
- Beard trimming and styling
- Hair coloring and perms
- Custom styling options

### 📅 Easy Appointment Management

- Intuitive booking interface
- Real-time availability checking
- Flexible scheduling options
- Easy modification and cancellation

### 👤 User-Friendly Experience

- Simple registration process
- Customizable user profiles with profile pictures
- Personal appointment history
- Service preference saving
- Easy professional selection

### ⚙️ Administrative Features

- Comprehensive navigation bar
- User management system
- Appointment oversight
- Performance tracking
- Report Management

### 📱 Modern UI/UX

- Clean and professional design
- Intuitive booking process
- Real-time updates
- Easy navigation

## 🛠️ Technical Stack

### Frontend

- React
- Vite
- Modern JavaScript (ES6+)
- Context API for state management
- Axios for API communication

### Backend

- Python Flask
- RESTful API architecture
- SQL Database
- Secure authentication system

### DevOps

- Docker containerization
- Docker Compose for easy deployment

## 🚀 Getting Started

1. Clone the repository
2. Start the services using Docker Compose:
   ```bash
   docker-compose up --build
   ```
3. Access the application:
   - Frontend: http://localhost:5173
   - Backend API: http://localhost:5000
